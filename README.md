Personal Portfolio Website 🌐

Welcome to my personal portfolio repository! This website is a clean, responsive, single-page portfolio built using pure HTML5 and CSS3 to showcase my projects and journey as an aspiring web developer.

✨ Features

Modern Dark Theme: Designed with a sleek slate-dark background and vibrant blue accents.

Fully Responsive: Adapts seamlessly across mobile, tablet, and desktop screens using CSS Media Queries.

Flexbox & CSS Grid Layouts: Built with Flexbox for navigation and Hero alignments, and CSS Grid for the projects showcase.

Smooth Animations & Transitions: Includes subtle CSS hover effects and a @keyframes fade-in entry animation.

Semantic HTML5: Built with standard accessibility and structure using <header>, <nav>, <main>, <section>, and <footer>.

Zero External Dependencies: Built without frameworks or JavaScript for fast performance and beginner-friendly clarity.

🛠️ Tech Stack

HTML5: Page structure, semantic tags, and content layout.

CSS3: Custom CSS variables, Flexbox, CSS Grid, media queries, keyframe animations, and styling.

Git & GitHub: Version control and hosting via GitHub Pages.
